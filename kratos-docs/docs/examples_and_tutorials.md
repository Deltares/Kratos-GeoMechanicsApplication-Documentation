## Critical Head Analysis

This example demonstrates a critical head calculation. The input consists of three files:

- [`mesh.mdpa`](examples/critical_head_analysis/mesh.mdpa)
- [`MaterialParameters.json`](examples/critical_head_analysis/MaterialParameters.json)
- [`ProjectParameters_stage1.json`](examples/critical_head_analysis/ProjectParameters_stage1.json)

These input files have been generated by [D-Geo Flow](https://www.deltares.nl/en/software-and-data/products/d-geo-flow), which is part of the D-GEO Suite.
The user can recreate this input using the GUI of D-Geo Flow. After opening the application, the user can draw the geometry, assign material properties to the layers, define flow boundaries and assign a calculation type and calculation properties. In the [user manual of D-Geo Flow](https://download.deltares.nl/d-geo-flow), this is explained in more detail.
Once the calculation is started, the input files are written to %TEMP% (in the log messages the exact directory is specified).

For this example, the geometry is set up to validate the [Sellmeijer rule](https://tl.iplo.nl/@238341/rekenregel-sellmeijer/), equation 7.19, an analytical approach to calculate the critical head difference (1).
{ .annotate }

1. Sellmeijer, J.B., J.L. de la Cruz, V. van Beek en H. Knoeff. [Fine-tuning of the backward erosion piping model through small-scale, medium-scale and IJkdijk experiments](https://www.researchgate.net/publication/233366434_Fine-tuning_of_the_backward_erosion_piping_model_through_small-scale_medium-scale_and_IJkdijk_experiments). European Journal of Environmental and Civil Engineering 15(8), 1139-1154, 2011.

To run the calculation with Kratos, download these files to a directory of your choice. In addition, you need to download the [Python script](examples/critical_head_analysis/run_simulation.py) that will run the analysis and save it to the same directory where you have put the input files. Note that the Python script contains a few additional analysis parameters, including the minimum critical head, the maximum critical head and the head increment. The adopted values have been taken from the corresponding analysis with D-Geo Flow, where they are defined for the critical head boundary.

To actually run the analysis, we need to have a Python virtual environment set up, where the GeoMechanicsApplication has been installed. If you don't have that available yet, please follow along the steps described in the [Getting Started](getting_started.md) section first. Assuming you have a Command Prompt with an active Python venv, you can now run the analysis with the command `python run_simulation.py`

The output of the simulation consists of a calculated critical head that has been written to the file `criticalHead.json` (which you will find in the same directory as the input files). In this example, the critical head was found to be equal to 1.1 meter.
